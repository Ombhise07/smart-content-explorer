# Smart Content Explorer

A React web application that fetches real technical articles from the Dev.to API and allows users to search, filter by tags, and manage favorites using Redux Toolkit.

---

## 🚀 Features

- Fetch real-time articles from Dev.to API
- Loading and error state handling
- Search articles by title
- Tag-based filtering (e.g., react, javascript)
- Article details page with full information
- Add / Remove favorites using Redux
- Separate favorites page
- Clean Redux Toolkit architecture

---

## 🛠 Tech Stack

- React
- Redux Toolkit
- React Router
- Vite
- Dev.to Public API

---

## 📦 Installation

Clone the repository:

```bash
git clone <your-repo-link>
cd smart-content-explorer
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

---

## 🌐 API Used

Dev.to Articles API  
https://dev.to/api/articles

---

## 📁 Project Structure

- `src/app/` → Redux store configuration
- `src/features/` → Redux slices (articles, favorites)
- `src/components/` → Reusable UI components
- `src/pages/` → Application pages
